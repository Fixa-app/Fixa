# Dev log — 5 juni 2026

## Supabase service role fix

**Probleem:** `POST /api/quotes/clients` gaf 403 op de `clients` tabel ondanks service role key.

**Oorzaak:** De PostgreSQL rol `service_role` had geen expliciete tabelrechten op `clients`, `quotes`, `line_items`, en `invoices`. Dit staat los van RLS — het is een database-niveau permissie.

**Oplossing:**
```sql
GRANT ALL ON clients, quotes, line_items, invoices TO service_role;
```

**Bijkomende wijzigingen:**
- RLS policy `members_select_own` toegevoegd aan `company_members`
- INSERT policy op `clients` verwijderd (conflicteerde met service role)
- `service_role` pattern vereenvoudigd: geen `global.headers` nodig, zelfde als onboarding save route
- Auth patroon gewijzigd: `userId` wordt meegestuurd vanuit frontend (via `createClient().auth.getUser()` bij klik), niet via server client — consistent met onboarding patroon

## Line item classificatie

### Nieuwe `item_type` waarde
```sql
ALTER TYPE line_item_type ADD VALUE 'transport';
```

Definitieve enum: `labor | transport | material | other`

**Toekomstige uitbreidingen (V2):**
```sql
ALTER TYPE line_item_type ADD VALUE 'equipment';      -- steigers, machines
ALTER TYPE line_item_type ADD VALUE 'subcontractor';  -- onderaannemer
```

### Parse prompt uitgebreid
`item_type` toegevoegd als veld in de Claude Vision parse prompt. Classificatielogica:

| item_type | Voorbeelden |
|---|---|
| `labor` | Uurloon, arbeid, dagtarief, overwerktarief, installatiewerk, montage, reparatie |
| `transport` | Voorrijkosten, reiskosten, parkeerkosten, transportkosten |
| `material` | Materiaalkosten, bevestigingsmateriaal, verbruiksmateriaal (geen merknaam) |
| `other` | Specifieke producten (Gewone agrimonie, Mosa tegel), afvoerkosten, huurkosten, onderaannemer |

### Onboarding save route
`item_type` wordt nu meegestuurd bij `products` insert:
```ts
item_type: item.item_type ?? 'other'
```

### Pre-fill bij nieuwe offerte
`/api/quotes/create` haalt bij aanmaken direct `labor`, `transport`, en `material` producten op en maakt die aan als line items op de quote. `other` items worden niet pre-filled.

### Onboarding products pagina
- Volledig vertaald naar Nederlands
- Generic items (`labor`, `transport`, `material`) bovenaan met microcopy: "Terugkerende posten — komen vooraf ingevuld bij nieuwe offertes"
- Specifieke items (`other`) eronder met label "Overige posten — klus- of productspecifiek"
