# Dev log — 4 juni 2026

## New quote flow: stap 1 en 2

### Architectuurbeslissing: multi-step flow
Gekozen voor multi-step flow (zoals onboarding) in plaats van één lang scherm. Redenen:
- Focused — één beslissing per keer
- Draft wordt direct opgeslagen in Supabase na stap 1
- State leeft in de DB via `quote_id` in de URL, niet in de browser

**Routes:**
- Stap 1: `/dashboard/quotes/new` → klant kiezen + adresgegevens
- Stap 2: `/dashboard/quotes/new/[id]/items` → job title, line items, totalen, aanhef, disclaimer
- Stap 3: `/dashboard/quotes/new/[id]/preview` → nog te bouwen

---

### Stap 1: klant selecteren

**Gebouwd:**
- `src/app/dashboard/quotes/new/page.tsx`
- `src/app/api/quotes/clients/route.ts` — GET (zoeken + recente klanten), POST (aanmaken), PATCH (bijwerken)
- `src/app/api/quotes/company/route.ts` — company_id ophalen
- `src/app/api/quotes/create/route.ts` — draft quote aanmaken

**Beslissingen:**
- Alle DB calls via server-side API routes met service role key (zelfde patroon als onboarding)
- Klant aanpassen (adres, telefoon, email) overschrijft direct de `clients` tabel — geen "wil je opslaan?" popup
- Adresveld is handmatig tekstveld met `// TODO: Google Places Autocomplete` — wacht op Google Cloud API key (op te zetten met Niek)
- Voice button verwijderd (was in wireframe, buiten scope V1)
- Progress bar toegevoegd: 1/3

**Openstaand bug:**
- `POST /api/quotes/clients` geeft 500 — waarschijnlijk verkeerde `SUPABASE_SERVICE_ROLE_KEY` in Vercel (Niek heeft deze gisteren aangepast). Wacht op Niek voor fix.
- RLS policy `members_select_own` toegevoegd aan `company_members` (was ontbrekend)
- INSERT policy op `clients` verwijderd (conflicteerde met service role)

### Stap 2: line items

**Gebouwd:**
- `src/app/dashboard/quotes/new/[id]/items/page.tsx`

**Features:**
- Job title (optioneel, niet zichtbaar voor klant)
- Line items met: title, beschrijving, aantal, stukprijs, BTW (0%/9%/21%)
- Optionele marge per item: percentage of vast bedrag, verborgen voor klant
- Supplier checkbox zichtbaar maar disabled ("binnenkort") — supplier flow is V2
- Dynamische totaalberekening: subtotaal per BTW-tarief, totaal
- Aanhef (pre-filled, bewerkbaar)
- Disclaimer (pre-filled, bewerkbaar)
- Concept opslaan / Verwijderen met bevestigingsdrawer (Vaul)
- CTA volgorde: secundair (verwijderen) boven, primair (concept opslaan) onder — conform best practice
- Footer is `sticky` ipv `fixed` zodat hij niet over de sidebar valt

**Beslissingen:**
- Marge per line item toegevoegd aan V1 — relevant voor onderaannemers (stukadoor, elektricien) zonder volledige supplier flow
- Parsed data uit onboarding (`products` tabel) wordt pre-gefilled als line items bij aanmaken nieuwe offerte — TODO: implementeren in `/api/quotes/create`
- Intro tekst en disclaimer pre-filled vanuit company_settings (TODO: ophalen via API)
